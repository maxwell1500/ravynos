(git `394fe3eac3` "Transplant Darwin 24.0 (xnu-11215) kernel"). SDK = the
ravynOS SDK mach tree (macOS 10.15 / Catalina vintage). `ref` = number of
`libsystem_c` files referencing `mach/<header>`.

unreferenced by the component being built and require no decision: they stay
exactly as they are. Any estimate that quotes 46 overstates the work by 3x.

## What this does not settle

- Whether each Group A header has an xnu-11215 equivalent *under a different
  name*. Group A is where a rename search is needed before concluding a header
  must be kept as Catalina.
- `HOST_MAX_SPECIAL_PORT` / the host special-port numbering scheme, which is a
  coordinated ABI block and NOT a per-header decision. That one is `libsystem_kernel`'s
  blocker and is deliberately excluded from this document.
- The `_kernelrpc_*` signatures, which belong to whichever generation wins.

Provenance: counts measured by grep over `Libraries/Libsystem/libsystem_c/`;
header presence measured by filename comparison between the two mach trees.
